Task: QUALIFY THE OPPORTUNITY.

Read every source document listed below (RFP, questionnaire, meeting notes, account brief, in any mix).
Extract facts only from those documents. Never invent: if something is not stated, write "Not stated".
Cite the source file name after every extracted item, e.g. (rfp.pdf).

Reply with an Opportunity Brief in markdown, using exactly these sections:

## Business problem
## Objectives
## Scope
### In scope
### Out of scope
## Constraints (budget, tech, compliance, geography, contract)
## Deadlines (every date: questions due, submission, decision, go-live)
## Stakeholders (name/role, what they care about)
## Evaluation criteria (with weights if given)
## Assumptions (things you had to assume; each one is a question to confirm)
## Open questions (missing or ambiguous information, one per line, ordered by impact)
## Conflicts (where documents disagree: quote both sides with sources)
## Qualification risks (risk, why it matters, High/Med/Low)

Do not write solution design or code at this stage.
